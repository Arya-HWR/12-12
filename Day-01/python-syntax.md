# Python Syntax — Day 01

## 1. Indentation
Python uses indentation to define code blocks. The standard is 4 spaces.

## 2. Colon (:)
A colon introduces a code block after statements such as `def`, `if`, `for`, and `while`.

## 3. Assignment vs Comparison
- `=` assigns a value.
- `==` compares two values.

## 4. Common Symbols
- `()` — Function calls and parameters.
- `[]` — Lists and indexing.
- `{}` — Dictionaries and sets.

## 5. Variables
Python is case-sensitive. `score` and `Score` are different names.

## 6. Comments and Strings
- `#` starts a comment.
- Strings can use single or double quotes.

## 7. Functions
- `def` defines a function.
- Parameters receive values.
- `return` sends a result back to the caller.
- Indentation defines the function body.
